# The Smile Hub - Dental Care Clinic Website

A multi-page website recreating the classic aesthetic of a 2010s family and cosmetic dental care practice.

## 🦷 Pages Included

- **Home (`index.html`)**: Hero banner, quick appointment banner, featured services, lead dentists preview, patient reviews carousel, and clinic hours.
- **About Us (`about.html`)**: Clinic story, philosophy, sterilization standards, and milestones.
- **Services (`services.html`)**: Comprehensive breakdown of general, cosmetic, restorative, and pediatric dental treatments.
- **Our Doctors (`doctors.html`)**: Detailed profiles of the dental team (Dr. Priya Sharma, Dr. Arjun Mehta, Dr. Meera Nair) with credentials and specialties.
- **Book Appointment (`appointment.html`)**: Online appointment booking form with instant validation and confirmation receipt.
- **Patient Reviews (`reviews.html`)**: Verified patient testimonials and review submission modal.
- **FAQs (`faqs.html`)**: Frequently asked questions with interactive accordion toggles.
- **Contact & Location (`contact.html`)**: Clinic contact information, working hours, interactive inquiry form, and location map.

## 💻 Tech Stack

- **HTML5 & Semantic Markup**
- **Vanilla CSS3** (Classic 980px centered layout, gradient navigation, retro glossy buttons, and clean responsive adaptations)
- **Vanilla JavaScript** (Form validations, interactive accordions, mobile navigation, and modal dialogues)

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via any static web server (such as Live Server, Python `http.server`, or GitHub Pages).
